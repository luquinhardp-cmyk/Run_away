# Assets originais — ECOS 0.2

Mapas: `textures/pbr/manifest.json` (10 materiais, 60 PNGs, duas resoluções). Recursos PBR editáveis: `materials/`. Modelo/rig/animações: `models/escutador_manifest.json`, `escutador.glb` e `escutador_low.glb`. Fonte Blender com imagens empacotadas: `source/escutador.blend`.

Todos os mapas, geometria, animações, ícone e WAVs são originais do projeto, gerados pelas ferramentas em `tools/art/`. Não foram reutilizados pixels ou modelos das referências. Não há música, fotografia, escultura ou áudio de terceiros. Os assets são destinados ao uso e modificação pelo titular deste projeto; não se definiu licença pública de redistribuição do projeto.

Ferramentas externas: Godot 4.7.2 (MIT), Blender 4.5.15 LTS (GPL) e NumPy (BSD). Essas ferramentas não são recursos artísticos copiados para o jogo. O jogo usa a fonte padrão da engine; não redistribui fonte proprietária do Windows.

O modelo é uma primeira versão artística de malha anatômica segmentada, com rig e materiais reais. Ainda requer acabamento manual e retopologia contínua para uma produção final. Documentação detalhada em `docs/DIRECAO_ARTE_TERROR.md`, `CRIATURA_PRINCIPAL.md` e `BIBLIOTECA_MATERIAIS.md`.
