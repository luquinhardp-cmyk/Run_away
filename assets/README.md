# Assets

Ícone SVG, geometrias, materiais procedurais e sons foram criados para este protótipo. Não há modelos ou áudio de terceiros. Os WAVs foram sintetizados em PCM mono 22.050 Hz, com amplitude de origem limitada; os volumes dos buses também são ajustáveis.

O modelo da criatura é um placeholder 3D feito com primitivas e animação procedural de tronco/membros. As paredes usam NoiseTexture2D 256². Não são arte ou áudio finais.
